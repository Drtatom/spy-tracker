# SPY Market Tracker

Un script ligero para rastrear el rendimiento del ETF SPY, calculando métricas básicas y tendencias de mercado.

## Características
- Obtención de datos históricos mediante `yfinance`.
- Cálculo de media móvil mensual.
- Generación de reporte en formato JSON.

## Instalación
```bash
pip install -r requirements.txt
```

## Uso
```bash
python main.py
```
El reporte se guardará en `spy_report.json`.
